
# The Haunting Forest 🌲

*A first-person horror game set deep within a dark, unsettling forest.*

> **Coming soon to itch.io!** 👻

## About the Game

The Haunting Forest is an atmospheric first-person horror game currently in development using Unity. Explore a mysterious forest, search for strange objects, and try to find your way out while something roams among the trees.

## Features

- 🌲 Atmospheric forest exploration
- 🔦 First-person gameplay
- 🗝️ Collectible objects and a journal to track discoveries
- 👹 An enemy wandering through the forest
- 🌫️ Immersive ambience and sound effects
- 🏃 Exploration, movement, and survival mechanics

*Features and gameplay are subject to change during development.*
